# Nightwatch

> *All your alts, under one moon.*

A focused, lightweight alternative to Altoholic for WoW Retail 12.0+ (Midnight). Nightwatch tracks your characters, professions, currencies, gold, and inventory across all alts and realms — all in one clean Midnight-themed UI.

---

## Features

### Character Summary
- Faction icon, class-colored name, level, equipped iLevel, gold, rested XP, last login
- All visible characters shown in a clean list with zebra striping

### Profession Skills
- Primary professions (icon + total skill across all expansions)
- Secondary professions (Cooking, Fishing, Archaeology) as icon columns
- Hover tooltip shows full per-expansion breakdown (Classic → Midnight)
- Updates live when you open a profession window — no reload needed

### Currencies
- Grouped by expansion
- Icon per currency, account-wide currencies shown once, capped amounts highlighted

### Inventory Search
- Search across bags, reagent bag, bank, and warbank for all characters
- Results show character name, source, and count

### Item Tooltips
- Hold your modifier key (default: Alt) while hovering any item to see counts across all characters
- Shows bags, reagent bag, bank, and warbank breakdown per character

### Settings
- 7 colour themes including accessibility options (deuteranopia, protanopia, tritanopia)
- Font and font size customisation via LibSharedMedia
- Tooltip modifier key selection (Alt / Ctrl / Shift)
- Per-character visibility toggle
- Minimap button toggle

---

## Slash Commands

| Command | Description |
|---------|-------------|
| `/nw` | Toggle the main UI |
| `/nw debug` | Toggle debug mode |
| `/nw prof` | Dump profession skillLine IDs to chat |
| `/nwdebug` | Toggle the debug log frame |

## Requirements

- LibStub, CallbackHandler-1.0, LibSharedMedia-3.0 (bundled)
